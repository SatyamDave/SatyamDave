I build agents that do real work, and the systems that keep them honest.

#### Agents and dev tools
- [**parley**](https://github.com/SatyamDave/parley): run several Claude Code agents on one repo; it plans a goal into a task graph, dispatches it and explains every change back to you
- [**simulation-labs**](https://github.com/SatyamDave/simulation-labs): a CI gate where computer-use agents attempt your signup and checkout on every deploy, and the merge is blocked when the flow breaks
- [**index-one**](https://github.com/SatyamDave/index-one): a tamper-evident chain of authority for multi-agent actions, written in Rust: proof of who authorized what across companies
- [**PHANTOM**](https://github.com/SatyamDave/phantom-agentic-hacking): autonomous black-box web pentesting with browser agents. *Best Dev Tool, YC Hackathon 2026*
- [**llm-detect**](https://github.com/SatyamDave/llm-detect): identifies the model and provider behind an endpoint

#### Simulation and forecasting
- [**real-world**](https://github.com/SatyamDave/real-world): message testing across 27 customer segments, backed by a public forecast track record
- [**Regulars**](https://github.com/SatyamDave/Regulars): runs thousands of simulated conversations, then checks them against what happened at a real dinner
- [**brain-research**](https://github.com/SatyamDave/brain-research): *Against Synthetic Optimism*, which measures and corrects sycophancy bias in LLM-simulated buying committees
- [**clinical-trial-agents**](https://github.com/SatyamDave/clinical-trial-agents): agents predict clinical trial outcomes, checked against blinded results

#### Markets
- [**quant-core**](https://github.com/SatyamDave/quant-core): an open template for agentic trading, where the agent proposes trades and a deterministic Rust engine enforces the risk rules
- [**fall_forward_labs**](https://github.com/SatyamDave/fall_forward_labs): a research platform with event replay, point-in-time data and walk-forward validation
- [**Fifty**](https://github.com/SatyamDave/5000): one autonomous session on a Robinhood Agentic account through the Robinhood Trading MCP
- [**bloombet**](https://github.com/SatyamDave/bloombet): a Bloomberg-style terminal for sports-market inefficiencies
